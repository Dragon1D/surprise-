# Bank Ide Konten — Akun Edukasi Finansial

30 ide siap diolah jadi postingan. Gaya bahasa: santai ala temen (gua–lu).
Status awal semua: **ide**. Ubah jadi *naskah → produksi → tayang* saat dikerjakan (lihat `bank-ide.csv`).

**Kode segmen:** M = mahasiswa · FJ = first jobber 22–27 · PK = pasangan muda/keluarga baru · PM = pekerja mapan 28–35
**Kode format:** 🎬 video animasi (skill `video-motion`) · 🖼️ carousel IG · 🧵 teks/thread
**⚠️ cek** = ada angka/klaim yang wajib diverifikasi ke sumber resmi sebelum tayang.
